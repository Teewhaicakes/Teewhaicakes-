# Teewhai Cakes and More

Red-and-black responsive bakery website starter.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — product catalogue, category filters, WhatsApp ordering and copy-account buttons
- `assets/hero.jpg` — supplied front-page image

## GitHub Pages
Upload all files/folders to the repository root, then enable GitHub Pages from:
Settings → Pages → Deploy from branch → main → /(root)

No Supabase connection is required for this first version.
